# Matemática actuarial

La matemática de los seguros de personas: demografía y proyecciones de población, la mortalidad como variable aleatoria, tablas y leyes de mortalidad, seguros y rentas vitalicias, primas netas y comerciales, reservas matemáticas y los seguros sobre varias vidas, contingentes y reversibles.

**Ver en línea:** https://aaramirez.github.io/mate-matematica-actuarial/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
